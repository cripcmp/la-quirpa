# Ferretería La Quirpa

Sitio web estático de Ferretería La Quirpa, Talagante.

## Archivos

- `index.html` — página principal
- `style.css` — diseño y versión responsive
- `app.js` — catálogo, comparación y presupuesto
- `logoqp.png` — logo con fondo transparente

## Publicar en GitHub Pages

Crear un repositorio, subir estos cuatro archivos a la raíz y activar:

Settings → Pages → Deploy from a branch → `main` → `/ (root)` → Save.

## Importante

Los precios del catálogo y la tabla de comparación son datos de demostración y deben reemplazarse por precios reales antes de publicar la información comercial.
